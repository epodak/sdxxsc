# 选品工具 MVP

这是一个基于Python和Gradio构建的产品信息管理工具的最小可行产品(MVP)。该工具旨在帮助用户方便地管理产品信息、生成产品描述以及优化多渠道内容。

## 功能特点

- **产品信息管理**：添加、编辑和查询产品信息
- **智能搜索**：根据关键词、产品类型和状态搜索产品
- **AI辅助生成**：使用AI生成产品描述和核心卖点
- **平台内容优化**：针对不同电商平台优化产品标题和描述
- **数据本地存储**：使用SQLite数据库安全地本地存储产品信息

## 技术栈

- **前端/UI**：Gradio（基于Python的UI框架）
- **后端**：Python
- **数据库**：SQLite
- **AI功能**：OpenAI API

## 安装与使用

### 环境要求

- Python 3.7+
- 互联网连接（用于AI功能）

### 安装步骤

1. 克隆本仓库或下载源代码

2. 安装依赖

```bash
pip install -r requirements.txt
```

3. 配置AI功能（可选）

如果需要使用AI辅助功能，需要设置OpenAI API密钥：

```bash
# Linux/macOS
export OPENAI_API_KEY="你的OpenAI API密钥"

# Windows
set OPENAI_API_KEY=你的OpenAI API密钥
```

4. 启动应用

```bash
python main.py
```

应用将在本地启动，默认访问地址为：http://127.0.0.1:7860

### 使用指南

1. **添加产品**：
   - 选择"添加产品"标签页
   - 填写产品基本信息，包括SKU ID、产品类型、名称等
   - 点击"添加产品"按钮保存

2. **浏览产品**：
   - 选择"产品浏览"标签页
   - 使用搜索框和筛选器查找产品
   - 点击"搜索"按钮显示结果

3. **AI辅助选品**：
   - 选择"AI辅助选品"标签页
   - 在"产品描述生成"子标签页填写产品基本信息
   - 点击"生成描述"获取AI生成的产品描述和卖点
   - 或在"平台内容优化"子标签页填写产品信息并选择目标平台
   - 点击"优化内容"获取针对特定平台优化的标题和描述

## 数据结构

应用基于《产品信息数据字段清单》设计数据结构，支持以下产品类型的特定字段：

- 数字化服务 (Digital Service)
- 现场执行服务 (Field Service)
- 软硬一体产品 (Physical Good)
- 培训课程 (Training)
- 组合套餐 (Bundle)
